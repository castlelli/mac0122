Tecnica:
Algoritmo: Union-find (conjuntos disjuntos)
Autores: Bernard A. Galler, Michael J. Fischer
Data: 1964
Conceitos: conjuntos disjuntos, union-find, árvore
Problema: Manter uma partição de n elementos sob as operações de unir dois conjuntos e dizer se dois elementos estão no mesmo conjunto.
---
# Ideia do algoritmo
Cada conjunto é uma árvore: id[i] guarda o pai do elemento i, e a raiz é o elemento com id[i] == i. Dois elementos estão no mesmo conjunto se e somente se as suas raízes são iguais. No início, cada elemento é a raiz de um conjunto só dele (id[i] = i), com sz[i] = 1.

Para um par p q, o programa sobe de p e de q até as raízes i e j. Se i == j, os elementos já estão conectados e nada acontece. Senão, os conjuntos são unidos ligando uma raiz à outra e o par é impresso.

A regra do peso mantém as árvores rasas: a raiz da árvore menor, medida por sz, passa a ser filha da raiz da maior, e o tamanho da raiz resultante é atualizado. Sem essa regra uma árvore pode virar uma lista e cada busca de raiz percorre muitos elementos.

# Implementação em C
O código é o programa 1.3 do livro de Sedgewick, a união ponderada de árvores (weighted quick-union), como impresso, com main sem tipo de retorno. A entrada é uma sequência de pares de inteiros.
[code]
#include <stdio.h>
#define N 10000
main()
  { int i, j, p, q, id[N], sz[N];
    for (i = 0; i < N; i++)
      { id[i] = i; sz[i] = 1; }
    while (scanf("%d %d\n", &p, &q) == 2)
      {
        for (i = p; i != id[i]; i = id[i]) ;
        for (j = q; j != id[j]; j = id[j]) ;
        if (i == j) continue;
        if (sz[i] < sz[j])
             { id[i] = j; sz[j] += sz[i]; }
        else { id[j] = i; sz[i] += sz[j]; }
        printf(" %d %d\n", p, q);
      }
  }
[/code]

# Complexidade
Sedgewick mostra que o algoritmo segue no máximo 2 lg N apontadores para decidir se dois de N objetos estão conectados (propriedade 1.3, p. 16). Cormen et al., com união por posto e compressão de caminho, dão tempo de pior caso O(m alfa(n)) para m operações, em que alfa é a inversa da função de Ackermann (p. 572); cada heurística sozinha dá O(m lg n) (p. 571). O programa 1.3 usa só a regra do peso.

# Histórico
O algoritmo para relações de equivalência é de B. A. Galler e M. J. Fischer, "An Improved Equivalence Algorithm", Communications of the ACM 7(5):301-303, maio de 1964; Knuth atribui a Fischer e Galler "um algoritmo elegante" para relações de equivalência, sem dar o ano (vol. 1, p. 353). A compressão de caminho e os limites justos são de Tarjan, a partir de 1975 (Cormen et al., p. 585).
